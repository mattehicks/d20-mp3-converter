Input

Drop music files or folders anywhere in this window.

Output folder

Leave empty to write each MP3 next to its source file. Originals are never changed, moved or deleted. Existing files are never overwritten.

Output profile

Always: MP3, stereo, ID3v2.3 tags, cover as baseline JPEG up to 500x500 and 200 KB, FAT32-safe names, files under 4 GB.
